## 1. ส่วนใดของงานที่ใช้ AI ช่วยมากที่สุด เพราะอะไร
ช่วยในส่วนโครงสร้างฟังก์ชัน JavaScript เชิงลึกและการจัดการข้อมูล เช่น ฟังก์ชันดึงข้อมูลที่ผสานระหว่างไฟล์ JSON และ localStorage (fetchAllProducts) และยังช่วยในด้าน feature เสริมด้วย

## 2. มีครั้งใดที่ AI ตอบผิดหรือไม่ตรงโจทย์ รู้ได้อย่างไร และแก้อย่างไร
มีบางครั้งที่ AI ให้โค้ด JavaScript ที่อ้างอิงถึงตัวแปรหรือ DOM Selector คลาดเคลื่อน ทำให้โค้ดไม่ทำงานตามที่คาดหวังผมรู้ได้จากการเปิด Developer Tools (Console) ในเบราว์เซอร์แล้วพบ Error หรือผลลัพธ์บนหน้าจอไม่แสดงผลวิธีแก้ไขคืออ่าน Error Message นำมาวิเคราะห์ Logic แล้วพิมพ์อธิบายบอก AI ให้ปรับแก้โค้ดเฉพาะจุดได้ถูกต้อง

## 3. เรื่องใดที่เข้าใจและทำเองได้โดยไม่ต้องพึ่ง AI แล้ว
ผมสามารถอ่านโค้ดส่วนใหญ่และสามารอธิบายกระบวนการทำงานและผลลัพทฺ์ของ code ตอนนี้ผมคิดว่าผมสามารถเริ่มต้นด้วยการเขียนโค้ดพื้นฐาณ
