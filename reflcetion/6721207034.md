# 1.ส่วนใดของงานที่ฉันใช้ AI ช่วยมากทีสุด เพราะอะไร
ผมใช้ AI Claude ช่วยทำ semantic html5 รูปแบบ พิมพ์โค้ด และ สร้างชื่อข้อมูล ตรงทำเป้าหมายที่ให้มาจาก PDF แบบพวกหมวกหมู่ และ เมนูหลักที่ต้องการ แล้วสร้างความคิดเห็นท่าเกิดมีปัญหาและต้องทำอย่างไร
# 2.มีครั้งใดที AI ให้คําตอบผิดหรือไม่ตรงโจทย์ ฉันรู้ได้อย่างไรและแก้ไขอย่างไร
ตอนที่ได้มา บางคำภาษาในพารากราฟที่ได้มา มันไม่ได้หรือไม่ตรง เพราะมันเป็นภาษาคอมพิวเตอร์ ไม่ใช้เป็นภาษาทั่วไป ทำให้อ่านแล้วไม่เข้าใจ แล้วผมไม่สั่งว่าต้องเป็นชื่ออะไร (ตอนนั้น อย่างไม่รู้ต้องเอาชื่อ) ก็เลยผมเปลี่ยนหลายคำเป็นภาษาที่ถูกต้องและเข้าใจง่าย เพื่อให้ชัดเจนว่าอันนี้คือไร แล้วมันทำอะไร
# 3.หลังทําโปรเจกต์ มีเรื่องใดทีฉันเข้าใจและทําได้ด้วยตนเองโดยไม่ต้องพึง AI แล้ว
ผมได้เข้าใจเรื่อง แล้วสร้าง semantic html ได้ แล้วได้เรียนรู้การใช้ class กับ ตัวคำอักษร แบบพารากราฟ รูปแบบที่ออกเป็นชิ้นส่วน การตัวเลือกเมนู และ การเข้าเว็บไซต์อื่น
