# 1. ส่วนใดของงานที่ใช้ AI ช่วยมากที่สุด เพราะอะไร
ผมใช้ AI ช่วยมากที่สุดในส่วนของการจัดโครงสร้างโปรเจกต์และการจัดการข้อมูล JSON ร่วมกับ localStorage รวมถึงการปรับแก้โค้ด HTML เพื่อเอาโค้ดแบบ Inline (ทั้ง Inline Script และ Inline Style) ออกทั้งหมด แล้วย้ายไปเขียนรวมไว้ในไฟล์ภายนอกอย่าง css/style.css และ js/main.js แทน ตามหลักการ

# 2. มีครั้งใดที่ AI ตอบผิดหรือไม่ตรงโจทย์ รู้ได้อย่างไร และแก้อย่างไร
มีตอนที่ระบบดึงข้อมูลจากไฟล์ Data/products.json มีปัญหาหาไฟล์ไม่เจอ (Error 404 บน GitHub Pages) เนื่องจากชื่อโฟลเดอร์AIคิดว่าเป็น data (d ตัวเล็ก)แต่จริงในโปรเจกต์คือ Data (D ตัวใหญ่) ตอนแรก AI แนะนำให้เปลี่ยนชื่อโฟลเดอร์ใน Git แต่ผมเลือกแก้ปัญหาโดยการปรับตัวแปร JSON_URL ใน js/main.js แทน
# 3. เรื่องใดที่เข้าใจและทำเองได้โดยไม่ต้องพึ่ง AI แล้ว\
ผมเข้าใจและทำเองได้เกี่ยวกับการจัดการและเรียกใช้งานข้อมูลจากไฟล์ JSON (Data/products.json) ร่วมกับ localStorage สำหรับบันทึกรายการสินค้าที่ลงขาย และสินค้าที่สนใจ เข้าใจหลักการเขียนโค้ด HTML ที่ปราศจาก Inline Script และ Inline Style เพื่อให้โค้ดสะอาดและดูแลรักษาง่าย
