# Reflection — 6721207027

## 1. ส่วนใดของงานที่ใช้ AI ช่วยมากที่สุด เพราะอะไร
ใช้ AI ช่วยจัด Layout พวก CSS Grid กับ Flexbox เพราะขี้เกียจมานั่งกะระยะหน้าจอเองทีละพิกเซล ช่วยเซฟเวลาไปได้เยอะมากตอนทำ Responsive   

## 2. มีครั้งใดที่ AI ตอบผิดหรือไม่ตรงโจทย์ รู้ได้อย่างไร และแก้อย่างไร
มีตอนที่ AI เผลอเขียนโค้ดแบบใส่ Inline style หรือแนะนำไลบรารีภายนอก ซึ่งมันผิดกฎโปรเจกต์ที่ต้องใช้ Vanilla CSS ล้วน รู้ตัวเพราะตรวจโค้ดก่อนเอามาใส่ เลยสั่งให้มันแก้กลับเป็น Custom CSS ปกติ
​
## 3. เรื่องใดที่เข้าใจและทำเองได้โดยไม่ต้องพึ่ง AI แล้ว
ถ้าให้เขียนโค้ดทั้งหมดจากศูนย์เองเลยยังทำได้ยากและยังต้องพึ่ง AI คอยช่วยอยู่ แต่หลังจากทำโปรเจกต์นี้ทำให้พอเข้าใจโครงสร้างการเชื่อมโยงไฟล์ HTML, CSS, JS และพอจะอ่านโค้ด แก้ไขข้อผิดพลาด หรือปรับแต่งส่วนต่างๆ ตามที่ AI แนะนำได้เข้าใจมากขึ้น
