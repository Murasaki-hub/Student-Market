## 1. ส่วนใดของงานที่ใช้ AI ช่วยมากที่สุด เพราะอะไร
ใช้ AI ช่วยจัด CSS Grid/Flexbox กับทำ Responsive เพราะช่วยประหยัดเวลาในการจัดหน้าจอหลายขนาด

## 2. มีครั้งใดที่ AI ตอบผิดหรือไม่ตรงโจทย์ รู้ได้อย่างไร และแก้อย่างไร
AI เคยแนะนำให้ใช้ Tailwind CSS ซึ่งผิดโจทย์ที่บังคับใช้ Vanilla CSS เลยให้ AI แก้เป็นเขียน Custom CSS ปกติแทน

## 3. เรื่องใดที่เข้าใจและทำเองได้โดยไม่ต้องพึ่ง AI แล้ว
ตอนนี้เขียนโครงสร้าง Semantic HTML, จัด CSS layout และเขียน JavaScript DOM เองได้คล่องขึ้นโดยไม่ต้องพึ่ง AI แล้วครับ
