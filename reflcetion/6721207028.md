# Reflection — 6721207028

## 1. ส่วนใดของงานที่ใช้ AI ช่วยมากที่สุด เพราะอะไร
ผมใช้ AI ช่วยมากที่สุดในส่วนหาสาเหตุที่ฟีเจอร์แสดงเวลาลงประกาศขึ้นว่า "เมื่อสักครู่" ทุกใบ เพราะผมไม่รู้ว่าปัญหาอยู่ที่ฟังก์ชัน ที่ข้อมูล หรือที่การ deploy การถาม AI ช่วยให้แยกปัญหาออกเป็นส่วนๆ และรู้ว่าควรเช็กอะไรก่อน

## 2. มีครั้งใดที่ AI ตอบผิดหรือไม่ตรงโจทย์ รู้ได้อย่างไร และแก้อย่างไร
ตอนแรกผมถาม AI ว่าต้องเพิ่มโค้ดอัปเดตเวลาตรงไหน และ AI ให้โค้ดตัวอย่างทั่วไปมา
ทั้งที่ main.js ของกลุ่มมีฟังก์ชัน timeAgo อยู่แล้ว เพราะ AI ยังไม่ได้เห็นโค้ดของเรา
พอส่ง main.js ให้ดู AI จึงบอกว่าโค้ดครบแล้ว และสาเหตุจริงคือ postedAt ใน products.json
เป็นวันที่ที่ยังไม่ถึง (20–23 พ.ย.) ทำให้เวลาติดลบและถูกแสดงเป็น "เมื่อสักครู่"
ผมแก้วันที่ในไฟล์แล้ว แต่เว็บบน github.io ยังเหมือนเดิม ผมรู้ว่ายังไม่หายเพราะเปิดหน้าเว็บแล้วเวลายังขึ้นเหมือนเดิม
จึงเปิดไฟล์ JSON ผ่าน URL ของเว็บดู พบว่ายังเป็นค่าเก่า ซึ่งแปลว่าเว็บอ่านไฟล์จาก repo
บน GitHub ไม่ใช่จากเครื่องของผม และเครื่องของผมยังไม่ได้ติดตั้ง Git จึง push ไม่ได้
ผมแก้ไฟล์บนเว็บ GitHub โดยตรงแล้ว commit จากนั้นเวลาจึงแสดงถูกต้อง

## 3. เรื่องใดที่เข้าใจและทำเองได้โดยไม่ต้องพึ่ง AI แล้ว
ผมอธิบายได้ว่า postedAt ถูกสร้างด้วย new Date().toISOString() ตอนกดลงประกาศ
และ timeAgo เอาเวลาปัจจุบัน (Date.now()) ลบเวลาที่ลงประกาศ แล้วแปลงจากวินาทีเป็นนาที ชั่วโมง วัน
ผมรู้ว่าถ้าวันที่ในข้อมูลอยู่ในอนาคต ผลลัพธ์จะติดลบและเข้าเงื่อนไข seconds < 0
ผมเข้าใจว่า GitHub Pages เปิดเว็บจากไฟล์ใน repo เท่านั้น การแก้ในเครื่องจึงต้อง commit และ push ก่อน
และเข้าใจความต่างระหว่างข้อมูลตัวอย่างจาก JSON กับข้อมูลที่ผู้ใช้ลงใหม่ซึ่งเก็บใน localStorage
