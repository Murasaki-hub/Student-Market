# รายการฟีเจอร์
F1 ประกาศตัวอย่างใน data/products.json รวมกับประกาศใหม่ใน localStorage แล้วแสดงในรายการ

F2 ค้นหา + กรองตามหมวดหมู่ สภาพ (ใหม่ / ดี / พอใช้) และช่วงราคา + เรียงตามล่าสุด/ราคา

F3 ฟอร์มลงประกาศ: ชือสินค้า, หมวดหมู่, ราคา, สภาพ, รายละเอียด, จุดนัดรับ(สถานที่จริง), ช่องทางติดต่อและ มี validation ครบ

F4 พรีวิวการ์ดประกาศแบบ real-time ขณะกรอกฟอร์ม

F5 ทําเครืองหมาย “ขายแล้ว” (แสดงปายและทําให้การ์ดจางลง) และลบประกาศ (ถามยืนยันก่อน)

F6 รายการทีสนใจ (wishlist) บันทึกด้วย localStorage

ฟีเจอร์เสริม
- แสดงระยะเวลาทีลงประกาศ เช่น “2 ชัวโมงทีแล้ว”
- ปาย “ราคาดี” เมือราคาตากว่าค่าเฉลียของหมวดเดียวกัน
